# 左上角裝飾性假按鈕 — 設計

本次使用了 brainstorming 技能：需求澄清、方案比較與定稿。

**狀態：** 已批准（2026-04-04）

## 摘要

在視口左上角填補空白，新增一排**裝飾性**假按鈕（方案 1：線框方塊 + 大寫字母縮寫）。點擊時以 `alert()` 顯示佔位提示，**重點在視覺樣式**（細線框、hover / focus 時 `--accent` 輕微外發光），不接入真實功能。

## 視覺與交互

- **位置：** `position: fixed`，`top` / `left` 與現有頂欄感一致（例如 16px），`z-index` 與 `.hint-pill` 同級或略高，不遮擋中央提示文案。
- **結構：** 外層容器 + 三個 `<button type="button">`，橫向排列、小間距。
- **標籤（預設）：** `VIE`、`ARC`、`LUX`（純裝飾，無業務語義）。
- **字體：** 小號 sans-serif（與 `.hint-pill` 一類），`uppercase`，字距略寬。
- **常態：** 透明或極淡背景，邊框 `rgba(232, 224, 212, 0.25–0.4)`。
- **`:hover` / `:focus-visible`：** 邊框提亮，`box-shadow` 使用 `var(--accent)` 做輕外發光。
- **`:active`：** 輕微按下感（例如陰影略收或 `translateY(1px)`）。
- **觸控：** 最小點擊高度約 44px。

## 行為

- 每個按鈕 `click` → `alert('…')`，三條互不相同的短英文佔位句即可。

## 可訪問性

- 真實 `<button>`，鍵盤可操作；`aria-label` 標明為示範/裝飾用途（英文），避免讀屏將縮寫誤解為嚴肅功能。

## 測試

- 手動：三鍵各點一次，確認 alert 與 hover/focus 樣式；窄視窗下與 footer、中央 hint 不重疊。

## 範圍外

- 不接 API、不改 Three.js / layout 邏輯。
